# Python for Data Science

A collection of beginner-friendly Python lessons and practice exercises, organized by topic. The repository covers Python fundamentals, control flow, built-in data structures, functions, and object-oriented programming.

## Topics

| Folder | What you will learn |
| --- | --- |
| `01_Python Fundamentals` | Python basics and introductory exercises |
| `02_If-Else` | Conditions and decision-making |
| `03_Modules_in_Python` | Importing and using Python modules |
| `04_Loops` | `for` and `while` loops, nested loops, and loop control |
| `05_Strings` | Creating, accessing, and modifying strings |
| `06_Lists` | List operations, methods, and traversal |
| `07_Tuple+Sets+Dictionary` | Working with tuples, sets, and dictionaries |
| `08_Function` | Functions, scope, and lambda functions |
| `09_Oop` | Classes, objects, and object-oriented programming |

The repository root also contains introductory examples such as `01_pythonFundamentals.py`, `ifElse.ipynb`, `class.py`, and `class&Obj.py`.

## Getting started

You need Python 3 to run the `.py` examples. Open a terminal in the repository folder and run a Python file with:

```bash
python path/to/file.py
```

On some Windows installations, use `py` instead:

```powershell
py path\to\file.py

The `.ipynb` exercises are Jupyter notebooks. Open them in Jupyter Notebook, JupyterLab, or another notebook-compatible editor.

## Suggested learning order

Follow the numbered folders from `01` to `09`. Each folder contains small examples intended for practice; open the files and experiment with the code as you learn each topic.

## About

This repository is a personal learning collection for building Python skills useful in data science. Examples are for educational practice and may be expanded or refined over time.
