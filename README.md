## ▶️ Run the examples

You need Python 3 for `.py` files. Open a terminal at the repository root and run a file by giving its path:

```bash
python "01_Python Fundamentals/your_file.py"
```

On Windows, `py` may be used instead of `python`:

```powershell
py "01_Python Fundamentals\your_file.py"
```

The exact example filenames are listed inside each topic folder. To open a `.ipynb` notebook, use Jupyter Notebook, JupyterLab, or a compatible editor.

<details>
<summary><strong>First time using Python?</strong></summary>

1. Install Python 3 from [python.org](https://www.python.org/downloads/).
2. Open a terminal in this repository.
3. Run one example at a time and read the output.
4. Change a value or add a line, then run it again.

</details>

## 💡 How to get the most out of this repo

1. Follow the numbered folders in order.
2. Type or edit the examples yourself instead of only reading them.
3. Predict the output before running a program.
4. Keep your experiments small, and save useful variations as separate files.
